SQL Data Analysis Practice 📊
📌 Project Overview

This repository contains a collection of SQL queries designed to practice fundamental data analysis concepts using a sample sales dataset. The project focuses on extracting meaningful insights from data using SQL.

🎯 Objectives
Calculate overall sales performance
Analyze the total number of orders
Identify customer-wise sales
Categorize orders based on sales value
Find customers with above-average sales
🛠️ SQL Concepts Used
SELECT
SUM()
COUNT()
GROUP BY
HAVING
CASE WHEN
Subqueries
Aggregate Functions
